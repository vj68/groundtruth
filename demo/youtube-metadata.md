## Description

AI is accelerating software output—but speed does not automatically become organizational value.

GroundTruth is an institutional learning control plane for AI-native engineering. Five Gemini 3.5 Flash agents orchestrated with Google ADK turn real failures into verified causal knowledge, organization-wide controls, and human capability.

In this demo, GroundTruth performs a blind historical replay of real Kubernetes issue #29297. The later fixing PR is withheld from the agents. Starting from one reported ConfigMap failure, the system independently identifies the same four affected plugins later changed by Kubernetes maintainers—then validates the result with deterministic proof and preserves the lesson in an append-only SHA-256 chain.
